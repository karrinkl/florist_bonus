# florist_bonus
Bonus assignment on the subject of Network Application Programming. 
Requirements for fulfillment: 
1.	Based on the subject area entities, create classes describing them.
2.	Classes and methods should have names reflecting their functionality.
3.	To store lists or sets of classes, use class-collections.
4. Use OOP features: classes, inheritance, polymorphism, encapsulation.
5.	Each class should have a meaningful name and informative composition.
6.	Inheritance should be used only when it makes sense.
7.	Coding should use the java code convention.
8.	Classes should be competently bundled.
9.	Use files to store initialization parameters (Unless keyboard input is required).
10.	Provide for correct handling of incorrect user actions.
11.	Creating your own exception classes is encouraged.

Option 32. Flower system. Create the Flower class. Create objects-flowers of different names and costs. Collect a bouquet of flowers for a certain amount (set by the user from the keyboard). Input data: the cost of the bouquet (integer), output data: the bouquet - a list of flowers with a total cost equal to the specified value. Flowers in the bouquet can be repeated. If it is impossible to find a bouquet for the given amount, inform the user about it and ask to enter another amount. Sort the flowers in the bouquet by their cost; by their names (the sorting type is entered by the user). Find the number of flowers of a given type in the bouquet (roses, carnations, etc. - user input).
